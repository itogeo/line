# SkyLine Data Sources

## NOAA/NWS Weather Forecasts
- **What:** Point forecasts, gridded forecasts, alerts, hazards
- **Coverage:** All of Montana
- **API:** https://api.weather.gov

## NOAA/NWS Forecast Zones
- **What:** Zone-based forecasts and watches/warnings
- **Endpoint:** https://api.weather.gov/alerts/active?area=MT
