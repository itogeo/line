# Snowline

Daily snow-cover map of SW Montana from Sentinel-2, checked against SNOTEL.
Live at **[line.itogeospatial.com/snow](https://line.itogeospatial.com/snow)**.

* `pipeline/` turns imagery into maps. Start with [pipeline/README.md](pipeline/README.md).
* `site/` is the static site: `index.html` (map), `metadata.html` (Data), `methods.html`, `webcam.html`.
* Project overview, reproduction steps and licence: the [repository README](../README.md).
